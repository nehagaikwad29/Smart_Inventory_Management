# Smart Inventory Management

## 📌 Project Overview

Smart Inventory Management is a Machine Learning based system that predicts future product demand and provides intelligent inventory recommendations.

## 🎯 Objectives

- Predict product demand using historical sales data.
- Analyze inventory status.
- Calculate recommended reorder quantity.
- Reduce stock shortages and overstocking.
- Provide an interactive web application.

## 🤖 Machine Learning

**Algorithm:** Random Forest Regressor

The model is used to predict continuous product demand based on historical and date-related features.

## 📊 Model Performance

|---|---:|

| RMSE | 9.61 |
